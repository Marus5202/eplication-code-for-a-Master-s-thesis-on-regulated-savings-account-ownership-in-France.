# Replication-code-for-a-Master-s-thesis-on-regulated-savings-account-ownership-in-France.
Code treatment, Ownership and substitution  

Master's Thesis — Regulated Savings

This repository contains the R code used for the empirical analysis of my Master's thesis on the determinants of regulated savings account ownership in France.

The analysis focuses on Livret A, LDDS and LEP, using econometric models and data from the INSEE Wealth and Housing Survey (Enquête Histoire de Vie et Patrimoine).

Note: The underlying microdata are not included in this repository.
